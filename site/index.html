A terminal shows you output. It cannot tell you which session is blocked on a permission prompt, what any of them decided an hour ago, or why the file you are staring at changed. AgentSwarm reads your agents' own session records alongside the live terminal — so it can.

install

1Get it

Windows 10/11. The installer fetches WebView2 if you don't have it.

AgentSwarm_0.1.0_x64_en-US.msi

Windows SmartScreen will warn about an unsigned installer from a new publisher — that warning is accurate, and "More info → Run anyway" is your call to make. Or build from source below and skip the question entirely.

orBuild from source

git clone <repository>
cd agent-swarm/app
npm install
npx tauri build --no-bundle

Needs Node ≥ 20 and Rust. The binary lands in app/src-tauri/target/release/; scripts\add-to-path.ps1 puts agentswarm on your PATH.

2Check it

agentswarm --doctor

Seven checks — PATH, agents found, session records readable, config valid, git, environment, last crash. Every failing check prints the command that fixes it. If something breaks later, this is where the answer is.

3Open your swarm

agentswarm --swarm morning

A swarm is the set of panes you always open together — folder, label and permission policy per pane, in .agentswarm/recipes.json. A first run writes a starter you can edit. Plain agentswarm reopens whatever you had.

one key worth memorising

ctrl+shift+Peverything — swarms, panes, search, settings. Type three letters; mrn finds morning.
ctrl+shift+spacejump to whatever has been waiting on you longest
ctrl+shift+Ethis pane: raw terminal ⇄ plain english
ctrl+shift+Mevery session, in the order it happened
ctrl+shift+Dwhat changed on disk — and why
ctrl+shift+F / Ssearch every session ever · find in this pane
ctrl+shift+Opin — two panes share the stage
ctrl+shift+C / Vcopy / paste · right-click copies a selection, pastes without one

what it does not do

Most tool pages hide this section. This project was built on the rule that a wrong reading is worse than no reading — that applies to its own page too.

It is not a better plain terminal

Windows Terminal is more mature at being a terminal: tabs, arbitrary splits, years of polish. If you run one shell and no agents, use that.

Windows only, today

ConPTY, WebView2 and the job-object process cleanup are all Windows-specific. Nothing in the design prevents other platforms; nothing has been built for them.

Young, and honest about it

Built in the open, tested by its builder and its own self-driving test suite — 67 automated tests, a smoke run on the real binary, and a recording per build. It has not yet survived a thousand strangers. You may be early.

Search finds words, not meaning

History search is exact and cited — every hit names its transcript and line — but "what did I decide about auth" only matches if you said "auth".
