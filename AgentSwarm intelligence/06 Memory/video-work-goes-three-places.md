From 2026-08-02 onward, anything to do with making a video goes to **three**
places, not one:

1. **The project's own vault** beside the code — e.g.
   `E:\agent-swarm\AgentSwarm intelligence\`, `E:\gurutva\Gurutva Intelligence\`.
2. **The global mirror** in `E:\Second Brain\<Project> Intelligence\`.
3. **`E:\Second Brain\Video Intelligence\`** — the cross-project one.

"Video" here is broad and deliberately so: the finished video, the process used
to make it, the plan and storyboard, the tools and models chosen, the prompts,
the render settings, the failures, and the raw brainstorming that led to any of
it.

**Why:** the first two locations are project memory and are already the
convention. The third is new and is the point of the rule — video-making
know-how is the thing that should compound *across* projects. Every project's
video process feeds one place, so the next video starts from everything the
last one learned instead of from zero.

**How to apply:** when video work happens, write the note once and place it in
all three. Do not summarise differently per location — the same artifact,
mirrored. In the Video Intelligence vault, file it so it is findable by
technique and tool, not only by which project it came from, because the reason
it is there is reuse by a *different* project later.

**Where it is, as of 2026-08-02:** the vault exists and is populated —
`00 Start Here` (states this rule), `01 Process/The production loop that works`,
`02 Planning/Pacing — what the numbers say`, `03 Tooling/The stack that made the
AgentSwarm film`, `04 Brainstorms/The feed-clip format, reverse engineered`,
`05 Project Videos/AgentSwarm — intro film`, `06 Lessons/Why a film needs
different rules than the product`. The AgentSwarm mirror is
`E:\Second Brain\AgentSwarm Intelligence\07 Video\`.

**Second application, 2026-08-04** — the `vidpipe` faceless-video pipeline
(`E:\faceless-video-pipeline` code, `E:\content-workflow` data). Project vault
`E:\content-workflow\Content Workflow Intelligence\`, global mirror
`E:\Second Brain\Content Workflow Intelligence\`, and five technique-filed
notes added to Video Intelligence (`01 Process/Render time is the binding
constraint…`, `02 Planning/Concrete visual keywords beat abstract ones…`,
`03 Tooling/Free and CC0 sourcing that actually works…`, `05 Project
Videos/vidpipe…`, `06 Lessons/A green test suite proves nothing…`).

**One refinement learned while first applying it:** the three copies are *not*
identical. Project and global hold the working artefacts (brief, storyboard,
script, build scripts). Video Intelligence holds the **transferable** form —
written so a different project can use it without knowing this one, filed by
technique and tool, and stating measured numbers rather than impressions.
