Gurutva (`E:\space\gravity-posterior`, vault `E:\space\Gurutva Intelligence`)
went public on **2026-08-02**:

- repo public, **Apache-2.0** — github.com/vaishak-v-nair/Gurutva
- site **https://gurutva.vercel.app** (canonical); GitHub Pages is a mirror
  serving the same bytes from `docs/`
- release **v0.1.2**: a 70.8 MB unsigned Windows `.exe`, no Python needed
- CI green on Python 3.11–3.14 plus a Windows job

**Strategy decided the same day: forum first, not Hacker News.** The reasoning
matters more than the decision — on HN the buyer (a geoscientist holding a
gravity survey and a drilling decision) is roughly 1 in 10,000, so a Show HN
spends one-time launch attention on people who cannot use the tool. The SimPEG
Discourse thread is already warm and already the right audience. HN comes in
2-3 weeks, once the post can open with "N geoscientists ran it, here is what
broke."

**The only metric that counts is still zero: nobody has run it on their own
survey.** Do not let engineering polish substitute for that — the project's own
record names the pattern as *"I kept building depth when the gap was reach."*

Still open and all Vaishak's hands: `gurutva.ai` unregistered, no code-signing
certificate (the only thing that removes the SmartScreen red screen), gate 5's
research question.
