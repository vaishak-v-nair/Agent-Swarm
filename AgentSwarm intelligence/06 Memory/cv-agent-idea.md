Idea, captured 2026-08-02, deliberately unjudged: **"an agent that can build any
computer vision project / model / work easily."** Filed in
`E:\agent-swarm\AgentSwarm intelligence\03 Plans\P8 - Ideas (inbox).md`.

**Status: parked, not rejected.** Two products (AgentSwarm, Recall) are already
competing for the same 8 h/week under a written tournament gate; a third
candidate would make that gate meaningless. Reopen when the tournament resolves.

**Four questions it must answer in writing before it becomes real** — the same
discipline that made the Recall design survive two adversarial rounds:

1. **What threshold does it move?** The reference clip that prompted the idea
   states the principle: *"the story is not new capability, it is the price."*
   "Easier CV" is a wish; "a working model in an evening on the laptop you own"
   is a threshold.
2. **Is Vaishak the ICP?** AgentSwarm and Recall both work because he is the
   user and can observe himself free. If he has no CV project he actually needs,
   demand evidence starts at zero with no proxy.
3. **What is the one demo that proves everything?** The equivalent of Recall's
   "answer citing a gotcha written nowhere".
4. **Who converges?** Roboflow, Ultralytics, Voxel51, Lightly, every AutoML
   vendor. A far more crowded field than Recall's — the prior-work audit that
   kept Recall from being a PRAXIS rebuild is mandatory here.

See [[recall-memory-design]] for the gate discipline this is deferring to.
