## 2026-08-02 — a CV agent (new product candidate, not an AgentSwarm feature)

**"An agent that can build any computer vision project / model / work easily."**

Captured raw, deliberately unjudged. Filed here rather than acted on, because
two products are already competing for the same 8 h/week and a third would make
the [[P2 - Gates|tournament]] meaningless.

What it would have to answer before it becomes real:

- **What is the threshold?** The reference clip that prompted this said it
  outright: *"the story is not new capability, it is the price."* A CV agent is
  interesting if it moves a threshold — dataset-to-working-model in an evening,
  or training that runs on the machine you already own. "Easier CV" is not a
  threshold; it is a wish.
- **Who is the ICP, and is it you?** AgentSwarm and Recall both work because
  Vaishak is the user and can observe himself for free. Is there a CV project
  he actually needs? If not, the demand evidence starts at zero with no proxy.
- **What is the wedge moment?** One demo that proves everything — the equivalent
  of "answer citing a gotcha written nowhere". Without it this is a platform
  pitch, and platform pitches lose to wedges.
- **Who converges?** Roboflow, Ultralytics, Lightly, Voxel51, plus every
  AutoML vendor. The prior-work audit that saved Recall from being a PRAXIS
  rebuild is mandatory here too, and this is a far more crowded field.

**Standing constraint that applies:** nothing gets built until the current
tournament resolves. Reopen this when it does — with the four answers written
down, not argued verbally.
